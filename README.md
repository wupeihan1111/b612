# B612 單字星球

小王子主題的像素風多益單字遊戲，目標是 2027/1/9 的多益考試。

- 每天三座火山：兩座活火山學新字，一座死火山複習
- 間隔重複：答錯隔天回來，答對 1 → 3 → 7 → 14 天後再出現
- 常錯的字會解鎖電影或歌曲記憶句
- 進度存在瀏覽器裡，設定頁可以複製備份碼

## 加入單字

題庫在 `data/words.js`，每個單元一個 deck，對應 Hackers《新制多益 全新!TOEIC 單字大全》的 Day。

## 本機預覽

```bash
python3 -m http.server 8612
```

然後打開 http://localhost:8612
